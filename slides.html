State Management
In-Memory Relational Store & Query Operators
Real web applications depend on foreign-key relations, sub-resources, and complex range queries. MockSmith handles them completely in memory.
🔗

Sub-Resource Routing

Automatically binds child collections to parent primary keys with zero configuration:

GET /api/users/:userId/orders
GET /api/posts/:postId/comments
DELETE /api/customers/:id
✔ Automatically indexes foreign keys & supports cascading deletes.
🔍

Range & Match Operators

Native query parameter filtering supporting numbers, ISO timestamps, and text:

?price_gte=50&price_lte=200
?inStock_ne=false
?name_like=headphones
?_page=1&_limit=20&_sort=price
✔ Standardized across all generated REST endpoints.
🧬

Polymorphic `oneOf`

Resolves OpenAPI oneOf and anyOf schemas with discriminator mapping:

type: "card" | "bank_transfer"
card: { cardNumber, brand }
bank: { iban, bic }
✔ Strictly enforces contract alternatives on payload POST/PUT.

Chaos Engineering
Interactive Real-Time Chaos Interceptor
Simulate adverse production network environments on demand without code changes or third-party proxy daemons.
PHASE 1 • AUTH SIMULATION

Token Verification & Expiry

Intercepts requests and verifies Bearer token presence. Simulates token expiration after $N$ requests:

HTTP 401 Unauthorized
HTTP 403 Forbidden
PHASE 2 • LATENCY & JITTER

Gaussian Delay Distribution

Injects base latency delay + dynamic jitter bounds $[L - J, L + J]$:

Latency: 250ms (Slider)
Jitter: ±50ms (Randomized)
PHASE 3 • PROBABILISTIC FAULT

Error Rate Evaluation

Rolls uniform random float against configured error rate:

HTTP 429 Rate Limited
Retry-After: 5s header
HTTP 500 / 503 Outage
PHASE 4 • STATE EXECUTION

Healthy Request Passthrough

If no faults trigger, dispatches to RelationalStore and emits live SSE event:

HTTP 200 OK / 201 Created
data: {"method":"POST", ...}
